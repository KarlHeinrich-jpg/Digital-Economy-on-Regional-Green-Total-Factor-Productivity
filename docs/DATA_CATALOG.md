## 核心变量口径

### 数字经济代理指标

数字经济专利文件包含四类计数：

1. 当年申请的数字经济相关发明数量；
2. 当年授权的数字经济相关发明数量；
3. 当年申请的数字经济相关实用新型数量；
4. 当年授权的数字经济相关实用新型数量。

数字服务贸易文件提供数字贸易指数及四个分项，可作为数字化开放程度的拓展或替代指标。使用计数型专利变量时，可根据研究设计考虑 `ln(1 + x)`、人均化或存量化处理，并说明选择理由。

### 绿色全要素生产率

当前表格采用以下数据结构：

| 类别 | 字段 |
|---|---|
| 投入 | 年末就业人数、固定资本存量、能源消耗总量 |
| 期望产出 | 地区 GDP |
| 非期望产出 | 工业废水、工业二氧化硫、一般工业固体废弃物 |
| 指数 | ML 指数；规模报酬可变 / 不变与全局 / 非全局口径 |
| 累积值 | 绿色全要素生产率及对应的四种规模报酬 / 技术集合口径 |

该文件包含 30 个地区，少于多数控制变量数据的 31 个地区。建模前应通过反连接检查被剔除地区，并在样本说明中披露。

### 综合控制变量

[`衡量方式与合并数据.xlsx`](../常用的控制变量/21常用控制变量数据/衡量方式与合并数据.xlsx) 的 `控制变量` 工作表包含 36 列。主要计算口径包括：

| 变量 | 文件中的衡量方式 |
|---|---|
| 税负水平 | 税收收入 / 地区生产总值 |
| 财政支持力度 | 地方财政一般预算支出 / 地区生产总值 |
| 经济发展水平 | 人均 GDP |
| 社会消费水平 | 社会消费品零售总额 / 地区生产总值 |
| 城镇化率 | 城镇常住人口 / 常住人口 |
| 产业结构 | 第二、第三产业增加值或占比相关指标 |
| 城乡居民收入差距 | 城镇与农村居民人均可支配收入之比 |
| 人口密度 | 常住人口 / 土地面积 |
| 金融发展水平 | 贷款余额 / GDP，或存贷款余额之和 / GDP |

实际回归前请查看 `变量说明` 工作表，并核对百分比、小数、亿元、万人、吨等单位。

## 面板合并建议

推荐按以下顺序建立分析数据：

1. 建立唯一的省份编码表，统一简称、全称和行政代码；
2. 确定研究期与样本范围，以 GTFP 的 30 地区、2011–2023 年为基准生成骨架表；
3. 逐表检查 `(province_code, year)` 是否唯一；
4. 对解释变量与控制变量做左连接，输出未匹配清单；
5. 统一价格口径、单位和对数变换，记录插值、外推与缺失值处理；
6. 按空间矩阵顺序重排地区，并进行矩阵一致性断言；
7. 保存只读原始层、清洗层和建模层，避免直接覆盖原文件。

建议最终保留如下元数据：

```text
variable_name
variable_label
unit
source
source_url
coverage
transformation
missing_rule
last_verified_at
```

## 已知问题

- 大量带 `(1)`、`(2)` 的文件与未编号版本内容完全相同，会增加选择成本和仓库体积；
- 文件名、表头和脚本中同时存在中文地区名、数字编码和自定义 `id`；
- 市场化指数 2020–2023 年由脚本按历史平均增长率外推；
- Stata / MATLAB 脚本以教学模板为主，包含绝对路径、固定年份和占位变量；
- 仓库尚未提供统一的主回归数据、自动化清洗脚本、运行日志与最终结果表；
- 第三方数据、论文、压缩包和视频的许可需要分别核验。

如果数据文件与本文档出现不一致，应以原始文件及其来源说明为准，并提交 Issue 或 Pull Request 更新本目录。
